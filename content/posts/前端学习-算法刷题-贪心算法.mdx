贪心算法相对于动态规划，贪心算法每次都是选择当前的局部最优解，就是说，不需要状态转移，要选最大值就直接选最大值。局部最优解就可以获得全局最优解。难点是这个“最大值”是什么，以及如何证明。

第一个是**买卖股票的最佳时机**，那肯定是每个点减去其前面的最低点得到答案。

第二个是**跳跃游戏**，数组元素表示能跳的最大距离，问能否跳到终点，从前到后遍历，记录能跳到的最大距离是不是大于等于最后一个索引即可。注意点就是如果遍历的时候i > far了那就不行了，因为i这个位置遍历不到。i都跳不到，i之后也一定跳不到了。

第三个是**跳跃游戏2**，这次保证可以跳到，问最小跳数。策略是在第一跳的途中找到第二跳的最远距离，到最远距离了，再增加跳数。维护end相当于一跳的极限距离，far就是当前的极限距离。

```java
class Solution {
    public int jump(int[] nums) {
        int step = 0;
        int end = 0;
        int far = 0;
        for (int i = 0; i < nums.length-1; ++i) {
            if (i+nums[i] > far) {
                far = i+nums[i];
            }
            if (i == end) {
                step ++;
                end = far;
            }
        }
        return step;
    }
}
```

第四个是**划分字母区间**，所有字母划分到一个串里面，先维护每个字母最靠右的位置，遍历的过程中一直更新这个位置，到了就划分一下，比较容易。
