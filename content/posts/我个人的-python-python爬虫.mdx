# 02.爬虫基本思想

爬虫就是抓取目标互联网信息的自动化程序，一般经历请求网页/抓包，直接获取静态网页内容/模拟前端与后端交互从而获取信息，提取信息，整理信息，保存信息等步骤。如果目标信息是静态网页直接返回来的，也就是服务端渲染，那么页面上的信息可以直接通过解析获得。如果目标信息是通过js网络请求回来的，就要分析http参数，模拟目标网页的前后端交互逻辑，用你的爬虫程序去模仿这个过程，从其后端获取数据。在这个过程中，有些参数可能是上一个网页带过来的，有的是加密过的，这个就需要根据实际情况分析了。

# 03.爬虫需要注意的地方

就如我上面所说，现在的网页很多都是前后端分离，客户端渲染的。现在的一些流行框架如vue开发出的网页打包后一般会生成一个html页面，一些js文件和css文件，html里面的内容是很少的，大部分内容都是js动态渲染出来的，所以很多时候我们用requests请求回来的网页源代码都跟我们检查网页看到的不一样，因为检查工具是实时的，是js渲染后的内容。我们请求回来的只是那个html文件，里面引入了一些js，没有其余的信息。**理解这个很重要，这样我们才知道哪些内容应该去哪里找，为什么请求回来的网页“少了”。**
