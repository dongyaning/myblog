动态规划的核心魅力就在于通过**状态定义的递推性**，将多阶段决策问题转化为对 "最后一步操作" 的分析，而无需显式枚举所有组合。

以拼硬币的那个题为例（lc 322 零钱兑换），这是一个完全背包问题。

这个题目每次只需要遍历一遍coins就能得到正确的状态转移，原因就在于这已经覆盖了所有的可能了。这是动态规划的精髓。**只考虑最后一步。**把所有最后一步的可能覆盖，就已经覆盖了全集了，就已经覆盖了所有可能了，得出来的最优解就是全局最优解！

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] f = new int[amount+1];
        Arrays.fill(f, -1);
        f[0] = 0;
        for (int i = 1; i <= amount; ++i) {
            int min = Integer.MAX_VALUE;
            for (int coin: coins) {
                if (i-coin < 0 || f[i-coin] == -1) continue;
                min = Math.min(min, f[i-coin]);
            }
            f[i] = (min == Integer.MAX_VALUE? -1: min+1);
        }

        return f[amount];
    }
}
```

动态规划的核心就在于状态的定义和递推关系，状态定义不正确，可能就无法写出状态转移方程，状态递推不正确，就无法实现正确的状态转换，找到最优解，或者说不符合状态定义。

### 一维动态规划

直观来看，就是状态数组是一维的，即状态中只有一个变量。

第一个**爬楼梯**，这是一个经典的递归题目，用dp来解决就是递推了。状态定义为：爬i阶楼梯的爬法种类数。从这里也可以看出，从数学归纳法的角度来看，dp的起始位置一定是要有简单到已知的状态的，比如说只有0阶，只有1阶，这样才能初始化，才能递推下去。

第二个**杨辉三角**也比较简单，过。

第三个是**打家劫舍**，就是数组相邻位置不能都拿，问拿的最多是多少，也比较简单，对于每个位置，都只有拿或不拿，拿的话只能加上f[i-2]，不拿就可以加i-1了，取max。

第四个是**完全平方数**，这个题有点东西，重要的思想是：

1.这个数的枚举数组需要自己想出来，其实就是1->sqrt(i)

2.动态规划的精髓，只考虑最后一步，每个数字只需要枚举一次即可。

第五个是**零钱兑换**，完全背包问题，和上一个思路一样，只需要考虑最后一步！

第六个是**单词拆分**，f[i]定义为用wordDict能不能拼出来前i个字符，只考虑最后一步，那么遍历wordDict只需要看看前i个是不是以word结尾的，如果不是，那么一定不行。如果是，再看看剩下的是不是可以（已经处理好了，是前面的状态）。

第七个是**最长递增子序列**，f[i]定义为前i个元素并以i结尾的最长递增子序列，这个的基础做法是双层循环，每次找到前面比当前元素小的，最大的那个值+1作为当前状态值。但可以优化到O(nlogn)，使用贪心+二分的方法，技巧性比较强。考虑到最长递增，所以要递增的尽可能慢，用d[i]记录长度为i的递增序列末尾的最小元素。遍历nums，如果nums[i] > d[len]，则放进去len++，否则二分找到插入位置。这个算法之所以可以就是只要能放进去就一定存在这个长度的递增序列，且是值最小的，最大可能限度让序列更长。

TIPS：序列题也可以定义为以i结尾。

第八个是**乘积最大子数组**，找到乘积最大的连续子数组，这个题目比较特殊，因为不满足“最优子结构”，即当前状态的最优情况不是由上一个状态的最优情况转移过来的，因为由负值。解决方案是同时维护两个状态（之所以维护两个状态是因为状态转移需要两个状态，即最大值由最大值和最小值转移过来）。将f[i]定义为前i个元素且以第i个元素结尾的最大乘积值。那么最大值要么是当前元素，要么是当前元素乘前i-1个元素的最大值，要么是乘前i-1个元素的最小值。

第九个是**分割等和子集**，这个题目最重要的一步就是问题转化，将问题：是否可以将数组分为两个子集，使得两个子集元素的和相等。转化为：是否可以从数组中取出一个序列使得和等于数组元素总和的一半。和前面不一样的地方在于，这个是0/1背包问题，每个元素只能取一次，是个二维的问题，不知道为什么被放到一维动态规划了。f[i][j]定义为考虑前i个num且和为j的元素能不能取出来，每次就是取或不取，只要有一个满足，就是true，用或运算即可。

第十个是**最长有效括号**，有几种方法，先说动态规划，总体较麻烦，比较考验分类能力和状态递推能力。

### 多维动态规划

第一个是**不同路径**，就是从左上角走到右下角，过。

第二个是**最小路径和**，也是左上到右下，只能向右向下，这次是路径最短，也比较简单哈，过。

第三个是**最长回文子串**，这个要注意如何定义状态，如何遍历，回文串有一个性质，就是去掉两边依然是回文串，反之如果中间不是回文串，加上两边也一定不是回文串，所以由短到长遍历即可，遍历过程中更新答案。

第四个是**最长公共子序列**，这个就不能定义以i, j结尾了，这样反而不好转移，所以这个是不确定的，要具体问题具体分析。f[i][j]定义为text1的前i个字符和text2的前j个字符中的最长公共子序列，那么很显然，如果text1[i] == text2[j]， 就等于f[i-1][j-1] + 1， 否则就等于max(f[i-1][j], f[i][j-1]);

第五个是**编辑距离**，这个就是三个操作，将s1 变成s2，分别是插入、删除、替换。定义f[i][j]和上一个类似，s1的前i个换成s2的前j个需要的最小操作数。如果s1[i] == s2[j]，那就是f[i-1][j-1]；如果不等，那就是三个值取min，即min(f[i-1][j], f[i][j-1], f[i-1][j-1]) + 1。这三个值分别表示 插入（把i-1个换成j之后再插入一个）、删除（前i-1个变成j之后再删除一个）、替换（前i-1个变成前j-1个之后，再替换第i个为j一样的字符）。
