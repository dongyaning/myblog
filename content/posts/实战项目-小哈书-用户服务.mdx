这里再补一下数据库连接池吧。

首先，为什么需要连接池？

如果没有连接池，每次请求执行一次SQL，都要建立连接，查完再关闭，非常耗时。

| **问题**          | **说明**                                                           |
| ----------------- | ------------------------------------------------------------------ |
| 🐢 **性能极差**   | 建立 TCP 连接 + 认证登录 ≈ 10~100ms，远高于 SQL 执行时间（1~10ms） |
| 🔥 **资源浪费**   | 高并发时频繁创建/销毁连接，CPU、内存飙升                           |
| 💥 **连接数爆炸** | 数据库最大连接数有限（如 MySQL 默认 151），容易被打满              |
| 📉 **响应延迟高** | 用户等待时间变长，系统吞吐量下降                                   |

数据库连接池核心思想：提前创建一批连接，放入“池子”，用时借，用完还，不销毁。

连接池工作流程：

1.初始阶段

- 连接池根据配置（如 `initialSize=5`）**预先创建 5 个连接**
- 每个连接都处于“空闲”状态，等待被借用

  2.借用连接

- 池子检查是否有空闲连接

- 有 → 返回一个空闲连接（**毫秒级**）
- 无且未达上限 → 创建新连接
- 无且已达上限 → 等待或抛异常

  3.使用连接

- 执行SQL

  4.归还连接

- 连接池拦截 `close()` 调用
- 将连接状态改为“空闲”，放回池中
- **物理连接未断开**，可复用

**Druid 不只是单车池，还是个“智能调度中心”**，能监控每辆车的位置、速度、故障，甚至防偷盗。

因为对象服务里面像是修改用户信息里面，需要上传头像和背景图片啥的，需要用到oss对象存储服务，也就涉及到服务间调用了。

**OpenFeign** 是 Spring Cloud 生态中用于实现 **声明式、面向接口的微服务间调用** 的核心组件。

**OpenFeign = 声明式 REST 客户端 + 动态代理 + 负载均衡 + 编解码**

它的目标是：**让你像写本地接口一样调用远程服务**。

理解OpenFeign有点难度，需要对Spring Cloud和Spring Cloud Alibaba有一个整体认识。

先看一下怎么用的：

1.客户端（发起HTTP请求的模块）

```xml
<!-- OpenFeign -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>
```

openfeign不属于ali体系，是spring cloud原生提供的。把这个组件引进来，就可以在api模块声明Feign客户端了。

```java
@FeignClient(name = ApiConstants.SERVICE_NAME, configuration = FeignFormConfig.class)
public interface FileFeignApi {
    String PREFIX = "/file";
    /**
     * 文件上传
     *
     * @param file
     * @return
     */
    @PostMapping(value = PREFIX + "/upload", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
    Response<?> uploadFile(@RequestPart(value = "file") MultipartFile file);
}
```

其中：

- @FeignClient就是声明客户端
- name就是指的nacos里面的那个要访问的服务名，feign会访问nacos，获取对应的ip和端口
- 下面的file/upload就是访问的对应服务的接口地址

支持表单请求还要配置类：

```java
@Configuration
public class FeignFormConfig {

    @Bean
    public Encoder feignFormEncoder() {
        return new SpringFormEncoder();
    }
}
```

2.调用者

在需要调用的地方，引入api模块

```xml
<dependency>
    <groupId>com.quanxiaoha</groupId>
    <artifactId>xiaohashu-oss-api</artifactId>
</dependency>
```

然后在启动类加上注解：

```java
@EnableFeignClients(basePackages = "com.quanxiaoha.xiaohashu")
```

需要的地方注入即可：

```java
@Resource
private FileFeignApi fileFeignApi;
```

关于Spring Cloud和Spring Cloud Alibaba，可以认为SC是提供了一套规范，一套接口和一套默认实现，但是这套默认实现是可插拔的，类似于策略模式，预定义了一套策略。SCA定义了另一套策略，结合Sring boot的选择性自动装配，将Ali的生态集成进去。
