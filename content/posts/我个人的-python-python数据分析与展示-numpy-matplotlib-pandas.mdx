```python
import numpy as np

# ndarray数组
# 创建ndarray数组

arr3 = np.arange(1, 10 ,3) # 类似range函数

arr8 = np.linspace(1, 10, 3, endpoint=True)
arr9 = np.concatenate([arr1, arr2, arr4])

# 数组的维度变化
arr10 = np.zeros(shape=(2, 5))
arr11 = arr10.reshape((5, 2))
arr11.resize(1, 10)
arr11 = arr11.astype(np.int32) # 改变数组类型
arr12 = arr10.flatten()
```

# 06.Matplotlib库

matplotlib内部结构复杂，受matlab启发，推出了matplotlib.**pyplot**命令子库，相当于是**快捷方式**

```python
import matplotlib.pyplot as plt # plt约定俗成

plt.plot([1, 3, 5, 7, 9], [5,2,6,4,7]) # 参数表示x,y
plt.ylabel('y')
plt.axis((-5, 10, 0, 10)) # 四个参数分别表示x轴的数据范围和y轴的数据范围
plt.subplot(2, 2, 2) # 绘制子区域，参数表示nrows, ncols, plot_number
plt.show()
# 注意，需要先调用subplot，再调用plot，这样就可以在子区域绘制了，show函数是总体的开关。
```

# 07.pandas库

pandas库基于numpy的ndarray数组，提供了很多方便高效的**数据分析**方法。

同时，相较于numpy，pandas更加注重**数据的应用**形式，无论是Series还是DataFrame，都加入了易于使用的索引。

## 1.Series

**series类型由一组数据及与之相关的数据索引组成**

> 1.Series类似于一般的字典
>
> 2.Series即使指定了自定义索引，也会生成自动索引，但是二者不可混用
>
> 3.Series对象相加时会根据索引进行配对相加
>
> 4.Series对象可以随时改变并立即生效

## 2.DataFrame

**DateFrame是一个表格型的数据类型，每列值的类型可以不同。DataFrame既有行索引，又有列索引，常用来表示二维数据，也可以表示多维数据。**

```python
dic = {'城市': ['北京', '上海', '深圳', '广州'], 'GDP': [3124, 5453, 8435, 9638]}
df = pd.DataFrame(dic, index=range(1, 5))

df.loc(2) # df.loc(row_label, col_label)
df[a][b] # a是列索引名，b是行索引名

# 重新索引函数
df.reindex(...)
'''
参数如下：
index, columns: 新的行列自定义索引
fill_value: 重新索引中，用于填充缺失位置的值
method: 填充方法，fill向前，bfill向后
limit: 最大填充量
copy: 默认为True，表示生成新的对象
'''
```
