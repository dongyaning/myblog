**第一个是\*\***移动0\*\*，双指针，都从头开始，头头指针。看代码吧，left &lt;= right，对于初始的 0 值，两者一起移动。始终保持左指针左边都是非 0 值，左指针和右指针中间都是 0 值。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int n = nums.length, left = 0, right = 0;
        while (right < n) {
            if (nums[right] != 0) {
                swap(nums, left, right);
                left++;
            }
            right++;
        }
    }

    public void swap(int[] nums, int left, int right) {
        int temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
    }
}

```

**第二个是\*\***盛最多水的容器\*\*，就是要确定左右边界，和x轴组成的容器最多能盛多少水。首尾指针问题。首先，要理解首尾指针的位置代表什么，实际上代表的是后面遍历中所有可能作为答案边界的位置。思路是每次选择小的一边移动即可。

证明如下：

如果移动了大的一边，即我们做了如下假设：小的一边有可能会成为后续遍历的答案边界。设小的一边为x，和大的一边的距离为l，则现在的答案为 x\*l。我们可以证明，如果以x为边界，后续所以遍历的答案一定不会超过x\*l，因为距离在变小，高度一定&lt;=x。这样的话，我们的遍历就无意义了。我们需要尽量去找更高的答案。所以小的一边一定不会作为后续的答案边界了。

new:

这个实际上就是这样想的：面积 = 宽度 \* 高度，因为是首尾指针，一开始的宽度就是最大的，不管怎么走，宽度一定在减小。而高度是两边的 Min，容易保留“较小的一边”，那后面的答案一定不会比现在大了。高度不可能更大了，那继续遍历就无意义。

注意：当两边高度相等时，其实应该是两边都动，但实现上可以随便移动一边。

**第三个是\*\***三数之和**，就是给出所有三个数之和为0的三元组。**不重复只需要索引递增即可\*\*。这个题目要用双指针的话是必须排序的，只有有序才可以利用性质。三个数不好处理，两个数好处理，所以先固定一个nums[i]，求另外两个的和为-nums[i]即可。排序之后就是首尾指针，增大 / 减小（这个过程是在遍历第一个数的循环内部）。

首尾指针，排序之后很好证明，要变小只能左移r，变大只能右移l。

**第四个是\*\***接雨水\*\*。这个题目就是要找每个x左边的最大值和右边的最大值中的较小值。一种思路是先求得两个最值数组。但可以用双指针来优化。因为是Min(hlmax, hrmax)，所以我们可以用两个变量维护最大值，一个从左开始，一个从右开始。如果lmax &lt; rmax，这个时候虽然不知道右边的最大值是不是rmax，但是左边的最大值一定是lmax，又可知右边的最大值一定>=rmax。所以Min(lmax, rmax) = lmax，就可以得到 l 的答案了，r 也是类似的。

new：

这个和 **盛最多水的容器** 有异曲同工之妙，都是涉及到 “首尾指针两边取 Min”，对于这种情况，就可以证明了，一般就是谁小可以挪谁，把刚挪走的那一个位置的答案确定下来，因为这边小，而且这一边的真实 max 已经得出来了，这个 max 都比右边的小，说明再继续下去，这个答案也不会增大了。

一样大小的情况，就是可以都挪，证明和上面的逻辑类似。
