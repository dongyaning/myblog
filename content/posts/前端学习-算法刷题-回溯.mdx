回溯的题目一般就是dfs类似。我查了一下，回溯实际上是dfs的子集，**DFS 是一种通用的搜索策略，而回溯算法是 DFS 在 “组合搜索问题” 中的具体应用，更强调通过回退和剪枝解决带约束条件的问题。**

第一个是**全排列**，经典回溯算法，递归的时候遍历排列数，没被标记过的就可以用，比较基础，我贴个代码。

有一种交换写法不需要标记数组，但是不是字典序排列：

```java
public void backtrack(int n, List<Integer> output, List<List<Integer>> res, int first) {
    // 所有数都填完了
    if (first == n) {
        res.add(new ArrayList<Integer>(output));
    }
    for (int i = first; i < n; i++) {
        // 动态维护数组
        // 相当于填到first位置，first前面已经填过了，用后面还没填的填first位置。
        Collections.swap(output, first, i);
        // 继续递归填下一个数
        backtrack(n, output, res, first + 1);
        // 撤销操作
        Collections.swap(output, first, i);
    }
}

```

第二个是**子集**，返回数组的全部子集，是个组合问题，组合问题就保证下标有序即可，后一次在前一次的后面开始遍历。

第三个是**电话号码的字母组合**，麻烦题，没什么亮点，注意Map初始化的写法：

```java
Map<Character, String> phoneMap = new HashMap<Character, String>() {{
    put('2', "abc");
    put('3', "def");
    put('4', "ghi");
    put('5', "jkl");
    put('6', "mno");
    put('7', "pqrs");
    put('8', "tuv");
    put('9', "wxyz");
}};
// 这个写法是匿名内部类 + 初始化块
// 两层{{}}, 第一层相当于是创建了个HashMap的匿名继承类，内部的{}是初始化块，作用类似于构造函数。
```

第四个是**组合总和**，这个题目的特点是每个元素可以取多次，也是组合问题，解决方案就是组合的start不+1，下一次继续从那个元素开始取。

第五个是**括号生成**，给一个括号对数n，给出所有合法的括号形式。核心思路就是左括号只要还没写完就可以写，而只有左括号的个数大于右括号时，才可以写右括号。也就是说，左括号数量要时刻 >= 右括号数量。

第六个是**单词搜索**，在一个二维字符数组上搜索某连续的单词。这个广度优先也可以哈，深度优先就从所有第一个字符开头的位置搜索。记住递归回溯时要取消标记哈。

第七个是**分割回文串**，题意就是要把一个字符串分割，使得每个分割得到的串都是回文串，返回所有的可能。暴力就是每个位置都看是分还是不分。优化的手段可以用动态规划预处理。

第八个是**N皇后问题**，这个就不能朝四个方向走了，因为本来就不能朝四个方向放，那样有很多明显的无用计算，递归时直接行加一就行，记住放的列。也可以用位运算的方式来保存放置的位置信息。
