**最大子数组和忘了写了，我补一个，**这个就是相当于是贪心算法，前面的和大于 0，就继续加，小于 0 了，就直接甩掉前面的即可。

**第一个是\*\***合并区间\*\*，就是把有重叠的区间合并成一个。思路就是按左端点排序，遍历的时候维护现在看的区间的最大右端点，左端点在右端点内就可以合并，否则新开一个。注意判断一下最后一个如果还没合并的话，要把最后一个放进去哈。

**第二个是\*\***轮转数组\*\*，就是数组右移轮转K位。一种想法是用额外的空间。如果要求空间。有一个巧妙的翻转解法：

```java
nums = "----->-->"; k =3
result = "-->----->";

reverse "----->-->" we can get "<--<-----"
reverse "<--" we can get "--><-----"
reverse "<-----" we can get "-->----->"
this visualization help me figure it out :)
```

还有一个解法，不朴素，是循环链法，就是从数学上可以证明存在gcd(k, n)个循环链，可以正好只遍历一次每个元素遍历完。因为成一个链，所以每次覆盖的时候只需要把被覆盖的元素保存就行了。

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;
        int count = gcd(k, n);
        for (int start = 0; start < count; ++start) {
            int current = start;
            int prev = nums[start];
            do {
                int next = (current + k) % n;
                int temp = nums[next];
                nums[next] = prev;
                prev = temp;
                current = next;
            } while (start != current);
        }
    }

    public int gcd(int x, int y) {
        return y > 0 ? gcd(y, x % y) : x;
    }
}
```

**第三个是\*\***除自身以外其余元素的乘积\*\*，不能用除法。一种想法是维护L，R数组，ans[i] = L[i-1] \* R[i+1]。空间复杂度高，没必要，其实两趟遍历，从前往后，从后往前，不乘当前元素即可。

**第四个是\*\***缺失的第一个正数\*\*，hard。主要是难在时间复杂度On且空间复杂度O1上。如果没有空间要求，那么就是哈希。有的话就使用原地哈希。因为答案一定在[1, N+1]里面，所以我们对在[1, N]范围内的数据位置打上标记。如何标记也需要考虑，因为原数据是没有限制的，我们需要先修改。因为我们只关心[1, N]的数，不在这个范围的包括负数我们都可以变成另外的数。这样所有数都是正的，我们就可以用负号来标记了。核心特点；
