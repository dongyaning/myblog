链表类的题目有几个比较关键的操作：

- **头结点（哑结点，dummyHead）**

- 哑结点可以统一操作（头结点和非头结点，因为把所有信息结点都变成了非头结点）。
- 典型的应用场景：

- 插入
- 删除
- 交换

```java
ListNode dummyHead = new ListNode(0);
dummyHead.next = head;
ListNode temp = dummyHead;
```

- **交换场景下的视角前置**

- 典型题目：交换链表中的相邻两个结点
- 很重要的一点是：交换两个相邻结点实际上涉及到三个结点，考虑前置结点的思想很重要，有这个需求之后，就需要添加头结点了。

- **反转链表**

- 经典题目，prev和curr指针

```java
public void reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
}
```

- **相交链表（双指针思路，相当于循环指针）**

- 长度一样的话，一定能在第一次遍历就相交。
- 长度不一样的话，
- ![image.png](/images/posts/前端学习-算法刷题-链表/链表-1.png)
- 走a+b+c之后一定会相遇

- **快慢指针得到链表中点**

- **注意这里的中点说的是：**

- **偶数是前半段的尾部**
- **奇数是中间结点**

- 注意细节：while判断条件

```java
private ListNode endOfFirstHalf(ListNode head) {
    ListNode fast = head;
    ListNode slow = head;
    while (fast.next != null && fast.next.next != null) {
        fast = fast.next.next;
        slow = slow.next;
    }
    return slow;
}
```

- **环形链表**

- 快慢指针
- 如果要返回入环点，就需要推导了
- ![image.png](/images/posts/前端学习-算法刷题-链表/链表-2.png)
- 注意点：fast一定先入环，且在slow走完一周前，fast一定能追上它，因为slow都跑了两圈了，差值都有一圈了。
- 设head->入环点为x，入环点到相遇点为y，则slow一定走了x+y，那么fast一定走了2(x+y)。那也就是说，slow再走x+y就回来了，又因为入环点到相遇点是y，所以相遇点到入环点就是x。
- 因此，相遇之后，两个指针分别从head和相遇点往后走，相遇点就是入环点。

- **删除倒数第n结点**

- 要删除加入头结点
- 也是快慢指针，快指针先走n+1步，注意是n+1步，因为要删除倒数第n个结点，需要找到倒数第n+1个结点！
- 之后快慢指针同时走，fast为null了，slow就是目标位置了。

第十一个是随机链表的复制，就是链表中多了一个random结点，可能随机指向任意结点或空结点，要返回深拷贝。难点在于遍历时random指向的结点可能还没遍历到，还没被创建出来。一个想法是可以提前创建并用hash存起来，需要的时候拿出来接上即可。用递归的写法实现比较简洁，但整体空间复杂度较高。

另一种解法是先将链表 A->B->C 复制为 A->A'->B->B'->C->C'，将A'->B'->C'作为新的答案链表，那么原使用random.next就可以找到新结点了，非常方便，最后还原链表并取出答案即可。

第十二个是排序链表，the end of leetcode hot 100. 要求nlogn的时间复杂度，常数级空间复杂度。排序方法里面比较适合链表的也就是归并，而且时间上也可以。

这个题有两种归并方式，比较直观和经典的方式是自顶向下归并，即先递归拆分，直到长度为1，再执行归并。

贴个代码：

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) return head;
        // 快慢指针找到中点
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 递归
        ListNode head2 = sortList(slow.next);
        slow.next = null; // 切断中间的连线
        ListNode head1 = sortList(head);
        // 归并
        ListNode newHead = merge(head1, head2);
        return newHead;
    }

    ListNode merge(ListNode head1, ListNode head2) {
        ListNode dummyHead = new ListNode(-1), curr = dummyHead;
        while (head1 != null && head2 != null) {
            if (head1.val <= head2.val) {
                curr.next = head1;
                head1 = head1.next;
            } else {
                curr.next = head2;
                head2 = head2.next;
            }
            curr = curr.next;
        }
        // 剩下的全部加进去
        while (head1 != null) {
            curr.next = head1;
            head1 = head1.next;
            curr = curr.next;
        }
        while (head2 != null) {
            curr.next = head2;
            head2 = head2.next;
            curr = curr.next;
        }
        return dummyHead.next;
    }
}
```

另一种方式是自底向上归并，相对于上面的优势就是不需要递归的logn的空间了，相当于模拟递归过程。先两两一组，再四个四个一组，直到n大于等于链表长度。注意的点就是尽量枚举sublength也就是归并的一部分的长度，且记住指针前置的思想。同时，对于最后的不够长度的，也要进行归并。

第十三个是合并K个有序链表，我贴一个优先队列的解法：

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        PriorityQueue<ListNode> h = new PriorityQueue<>((a, b) -> a.val - b.val);

        for (ListNode node: lists)
            if (node != null) h.offer(node);

        ListNode dummyHead = new ListNode(-1), curr = dummyHead;
        while (!h.isEmpty()) {
            ListNode node = h.poll();
            curr.next = node;
            curr = curr.next;

            if (node.next != null) h.offer(node.next);
        }
        return dummyHead.next;
    }
}
```
