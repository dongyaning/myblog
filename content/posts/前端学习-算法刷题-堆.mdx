堆最好会手写哈，整理个模版出来。

第一个是**数组中的第K个最大元素**，这个可以用堆的方法写，还是比较直观的哈，时间复杂度是nlogn吧。第二个是快速排序的方式，快速排序的逻辑是每次都一定至少能确定一个元素的最终位置，如果这个位置正好是要的位置，就可以返回了。

用这个题来总结堆的写法和快速排序的写法。

堆解法：

```java
// 堆的写法模版

// 建堆的过程就是从一半减一开始，向左向上遍历结点，并向下调整
public void buildMaxHeap(int[] a, int heapSize) {
    for (int i = heapSize / 2 - 1; i >= 0; --i) {
        maxHeapify(a, i, heapSize);
    }
}

// 删除的逻辑就是用最后一个元素把第一个元素覆盖了，再从根节点向下调整。
void pop() {
    swap(nums, 0, i);
    --heapSize;
    maxHeapify(nums, 0, heapSize);
}

// 这个实际上就是从结点i向下调整，注意这个写法，同时要注意下标从0开始的话，左孩子是t*2+1
public void maxHeapify(int[] a, int i, int heapSize) {
    int l = i * 2 + 1, r = i * 2 + 2, largest = i;
    if (l < heapSize && a[l] > a[largest]) {
        largest = l;
    }
    if (r < heapSize && a[r] > a[largest]) {
        largest = r;
    }
    if (largest != i) {
        swap(a, i, largest);
        maxHeapify(a, largest, heapSize);
    }
}

// 有了模版之后题目很好写，建大根堆之后pop k-1次，再取堆顶元素即可。
```

快速排序解法：

```java
// 每次递归都能确定某个元素的最终位置，如果所确定的位置为倒数第k个位置，则返回该位置元素。
// 快排模版：
void quickSort(int[] nums, int l, int r) {
    // 1. 递归终止条件：当子数组长度为1或空时，无需排序
    if (l >=r) return ;

    // 2. 初始化分区参数：
    // - i 初始在左边界左侧（l-1）
    // - j 初始在右边界右侧（r+1）
    // - 基准值 x 选中间元素（避免极端情况如全排序数组导致最坏时间复杂度）
    int i = l-1;
    int j = r+1;
    int x = nums[(l+r) >> 1];
    // 3. Hoare 分区循环：双指针从两端向中间移动
    while (l < r) {
        // 3.1 移动左指针 i：跳过所有小于 x 的元素，直到找到 >=x 的元素
        do i++; while(nums[i] < x);

        // 3.2 移动右指针 j：跳过所有大于 x 的元素，直到找到 <=x 的元素
        do j--; while(nums[i] > x);

        // 3.3 如果指针未交错，交换左右指针的元素（确保左边 <=x，右边 >=x）
        if (i < j) swap(nums[i], nums[j]);
    }
    // 4. 递归排序左右子数组：
    // - 分区点为 j（因为当 i >= j 时，j 是左半部分的最右端）
    // - 左子数组：[l, j]（所有元素 <=x）
    // - 右子数组：[j+1, r]（所有元素 >=x）
    quickSort(nums, l, j);
    quickSort(nums, j+1, r);
}

// 对于这个题目，相当于是要找到升序数组中下标为n-k的那个元素。
// 策略是，如果 k<=j，则遍历左边，k > j，则遍历右边。最后如果l=r，就是找到了k那个位置了。
class Solution {
    public int findKthLargest(int[] nums, int k) {
        return quickSort(nums, nums.length-k, 0, nums.length-1);
    }

    int quickSort(int[] nums, int k, int l, int r) {
        if (l == r) return nums[k];
        int i = l-1, j = r+1;
        int x = nums[(l+r) >> 1];
        while (i < j) {
            do i++; while (nums[i] < x);
            do j--; while (nums[j] > x);

            if (i < j) {
                int t = nums[i];
                nums[i] = nums[j];
                nums[j] = t;
            }
        }
        // 以j为分界点，因为此时 i >= j, j是左边部分的右端点
        // 右半部分有 r-j 个元素
        if (k <= j) return quickSort(nums, k, l, j);
        else return quickSort(nums, k, j+1, r);
    }
}
```

第二个是前K个高频元素，典型的堆排序题目，主要是手写堆。

第三个是数据流的中位数，一个核心思想是维护左右两个序列，中位数是可以方便方便地根据中间元素动态得出来的。从中间分开，左边维护一个大根堆，右边小根堆，插入之后让两边的个数平衡，中位数可以由堆顶得出。
